# 合规检查清单

这个项目面向“用户完成小游戏后，主动观看激励广告领取金币”的合规模式。上线或接入真实广告平台前，请逐项确认。

## 广告平台政策

- 使用激励广告格式，用户必须主动点击按钮开始观看。
- 广告应作为领取游戏奖励的确认步骤，不应强制用户无限观看。
- 不诱导点击普通广告，不承诺点击广告获得现金。
- 不自动播放广告，不隐藏广告关闭入口。
- 不使用模拟器、脚本、自动化工具或虚假流量刷广告。
- 上线前将测试广告位替换为广告平台后台创建的正式广告位。

## 用户奖励

- 小游戏可以先产生“待领取奖励”，正式金币应在广告 SDK 回调 `onUserEarnedReward` 后发放。
- 金币、积分、提现流水必须存储在可信后端，客户端仅用于展示。
- 提现需要审核、风控和反作弊，不应仅依赖客户端状态。
- 清楚展示兑换规则、到账周期、失败原因和客服渠道。

## 隐私与数据

- 提供隐私政策和用户协议。
- 如投放个性化广告，需要接入用户同意管理流程。
- 明示收集的数据类型、用途、第三方 SDK 和用户权利。
- 按目标市场补充 GDPR、CCPA、COPPA 或本地法规要求。

## 发布前建议

- 接入登录和后端账户系统。
- 增加服务端广告验证或广告平台 SSV。
- 增加设备指纹、频控、提现审核、异常检测等风控能力。
- 使用 Play Console 测试轨道验证真实设备行为。
